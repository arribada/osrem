# osrem
This project is a remote electronic monitoring system (or REM).

It is a fork of [marlin-core](https://github.com/arribada/marlin-core), which is part of the [MARLIN project](https://resilience.esa.int/archives/projects/marlin).

The goal of this project is to simplify, maintain, and improve the code base to make it suitable for a simpler hardware setup (e.g. just a raspberry pi 5), and useful to a wider community.

Some code from the other parts of the MARLIN project (listed below) will be integrated as well.

* Code for the MARLIN controller device: [marlin-controller](https://github.com/arribada/marlin-controller)
* Code for the MARLIN low-power module: [marlin-lpm](https://github.com/arribada/marlin-lpm)
* Code for the MARLIN cloud dashboard: [marlin-dashboard](https://github.com/arribada/marlin-dashboard)
